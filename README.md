# Pure Black High Contrast

Pure Black High Contrast is a high-contrast theme for [Zed](https://zed.dev/).  
It uses a true black (`#000000`) background and bright text for clear reading.

![Pure Black High Contrast](https://github.com/Dhanush-S-Gowda/zed-theme-Pure-Black-High-Contrast/blob/main/zed-theme.png?raw=true)

## Extension

- Zed extension page: https://zed.dev/extensions/pure-black-high-contrast-theme

## Install

### Option 1: Install from Zed Extensions (recommended)

1. Open Zed.
2. Open **Extensions**.
3. Search for **Pure Black High Contrast**.
4. Select **Install**.
5. Go to **Settings → Theme** and select **Pure Black High Contrast**.

### Option 2: Install as a dev extension

1. Clone this repository:

   ```bash
   git clone https://github.com/Dhanush-S-Gowda/zed-theme-Pure-Black-High-Contrast.git
   ```

2. In Zed, open the command palette and run:

   ```text
   zed: extensions
   ```

3. Select **Install Dev Extension**.
4. Select the cloned repository folder.

## Key features

- True black editor background (`#000000`)
- High-contrast foreground text
- Clear active line and selection states (`#FFFFFF1A` active line, `#FFFFFF33` selection)
- Readable syntax colors:
  - Keywords use purple (`#D78BFF`)
  - Functions use blue (`#60A5FA`)
  - Types and operators use cyan (`#67E8F9`)
  - Strings use green (`#8FE388`)
  - Numbers and constants use yellow (`#FFD166`)
  - Properties and parameters use soft red (`#FF6B6B`)
- OLED-friendly UI

## Compatibility

- Editor: [Zed](https://zed.dev/)
- Theme schema: https://zed.dev/schema/themes/v0.2.0.json
